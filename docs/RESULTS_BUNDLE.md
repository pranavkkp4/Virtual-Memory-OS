# Results Bundle Guide

This document defines the submission-ready results scaffold for the Virtual
Memory project. It is meant to keep the experiment outputs organized and easy
to reproduce.

## Folder Roles

### `results/raw/`

Store per-run artifacts here.

- Raw JSON output from single runs or trial batches
- CSV logs for isolation/shared runtime measurements
- Trace metadata and environment snapshots
- Per-run hypothesis inputs before aggregation

### `results/processed/`

Store summarized analysis here.

- Aggregated means, medians, standard deviations, and confidence intervals
- Slowdown summaries and fairness metrics
- Hypothesis evaluation tables for H1, H2, and H3
- Cleaned CSV files ready for report tables

### `results/figures/`

Store publication-style plots here.

- Page-fault versus memory-scale plots
- Slowdown and fairness charts
- Trace-driven comparison figures
- Any final PDF or PNG figures used in the report

### `results/tables/`

Store final table outputs here.

- Experimental setup table
- Main outcome table by workload
- Hypothesis evaluation summary
- Statistical significance tables

### `results/demo/`

Store the smallest reproducible demo here.

- A short walkthrough
- One or two tiny traces
- A small regeneration script or notebook
- Any notes needed to reproduce the headline outputs

## Minimal Bundle

A good submission bundle can be small and still complete:

- `2` synthetic workloads
- `2` trace-driven workloads
- `3` algorithms
- `2` allocation policies
- `4` memory scales
- `10` repetitions per configuration

That is enough to show trace support, slowdown measurement, fairness
comparison, and hypothesis evaluation without requiring a huge benchmark run.

## Reproduction Checklist

1. Install dependencies.
2. Run the chosen experiment matrix.
3. For a tiny checked-in walkthrough, run `python results\demo\generate_demo_bundle.py --output-dir results\demo\final_bundle`.
4. Collect raw outputs under `results/raw/`.
5. Aggregate metrics into `results/processed/`.
6. Generate plots in `results/figures/`.
7. Export summary tables into `results/tables/`.
8. Update `results/demo/README.md` with the exact replay command.

## Suggested Final Artifacts

- `results/raw/*.json` and `results/raw/*.csv`
- `results/processed/*.csv`
- `results/figures/*.png`
- `results/tables/*.md` or `results/tables/*.csv`
- `results/demo/README.md`
- `results/demo/demo_trace.csv`
- `results/demo/generate_demo_bundle.py`

## Notes

- Keep checked-in examples small and representative.
- Avoid mixing temporary scratch outputs with final deliverables.
- If a file is generated by a script, note the script name in the filename or
  nearby documentation.
